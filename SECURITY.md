# Security policy

Please **don't** report security issues in public issues. Use GitHub's private vulnerability
reporting ("Report a vulnerability" under the repository's Security tab), or email
**security@keepjay.com**.

Include what you found, how to reproduce it, and the version or commit. We aim to acknowledge
reports within 5 working days.

Scope includes the core and CLI in this repository. Hosted services (sync, AI
gateway, accounts) are not in this repository, but reports about them are welcome through the
same channels.
